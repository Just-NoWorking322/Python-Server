# 🚀 Проект «ТОП СТР Enterprise» (TOP STR Enterprise)

Серверная часть (Backend API на Django REST Framework) для онлайн-сервиса поиска специалистов (сантехники, электрики, репетиторы, клинеры, IT-мастера, стилисты) и оформления клиентских заявок.

## 🛠 Архитектура и стек технологий

* **Python 3.14**
* **Django 6.1**
* **Django REST Framework (DRF) 3.18** — мощный API-фреймворк
* **SimpleJWT** — безопасная аутентификация по JWT токенам (Access + Refresh)
* **django-filter** — фильтрация по категориям, статусам и ценам
* **drf-yasg** — генерация интерактивной Swagger / OpenAPI документации для фронтендеров
* **LocMemCache** — кэширование в оперативной памяти с мгновенной инвалидацией при изменениях

## 📋 Реализованные требования ТЗ

### 1. Каталог услуг (карточки мастеров)
* **Название услуги:** валидация на минимальную длину (не менее 5 символов).
* **Описание:** подробное описание входящих в работу задач.
* **Категории:** Ремонт (`repair`), Уборка (`cleaning`), Обучение (`education`), Красота (`beauty`), IT (`it`), Другое (`other`).
* **Цена и Скидка:** базовая цена + скидка от 0 до 90%.
* **Итоговая цена:** сервер автоматически вычисляет `final_price` по формуле `price * (100 - discount) / 100` и отдаёт клиентам готовое значение.
* **Статус:** флаг «Принимаю заказы сейчас» (`is_active`).
* **Автор:** система автоматически фиксирует текущего авторизованного мастера при создании.

### 2. Строгие права доступа (Permissions)
* **Просмотр каталога:** открыт абсолютно всем (включая неавторизованных гостей).
* **Добавление услуги:** только зарегистрированные специалисты, вошедшие в свой аккаунт.
* **Редактирование и удаление услуги:** разрешено **только** мастеру-автору этой услуги либо Администратору сервиса. Чужие услуги защищены от изменений (403 Forbidden).
* **Администратор:** полный контроль над всеми услугами и пользователями.

### 3. Удобство для клиентов (Поиск, фильтры, сортировка, пагинация)
* **Фильтры:**
  * По категории: `?category=repair`
  * По статусу актуальности: `?is_active=true`
  * По диапазону цен: `?min_price=1000&max_price=5000`
* **Поиск:** полнотекстовый поиск по названию и описанию (`?search=сантехник`).
* **Сортировка:** от дешевых к дорогим (`?ordering=price`), от дорогих к дешевым (`?ordering=-price`), по новизне (`?ordering=-created_at`).
* **Пагинация:** порционная выдача по 5 записей на страницу (`?page=1&page_size=5`).

### 4. Заявки от клиентов (Заказы)
* **Оформление заказа («Заказать»):** любой клиент (даже гость без аккаунта) указывает имя, контактный телефон и комментарий.
* **Конфиденциальность заявок:** мастер в своем личном кабинете видит **только** заявки, поступившие на его собственные услуги. Чужие заказы ему недоступны!
* **Удаление заявок:** удалять заявки из базы имеет право **только Администратор сервиса**. Мастерам удаление строго запрещено.

### 5. Скорость работы (Блок «Топ-5 популярных услуг» + Кэш)
* Эндпоинт `GET /api/services/top/` отдаёт топ-5 актуальных услуг.
* Ответ кэшируется в быстрой памяти (`LocMemCache`). В заголовках возвращается статус `X-Cache: HIT` (из кэша) или `X-Cache: MISS` (первый расчет).
* **Мгновенная инвалидация:** как только любой мастер добавляет новую услугу, редактирует её или поступает новый заказ, сигнал Django мгновенно сбрасывает кэш, и данные обновляются!

### 6. Вход в систему и документация
* **JWT-токены:** авторизация по логину и паролю с выдачей `access` и `refresh` токенов.
* **Стандартная Django Admin:** панель `/admin/` с красивым русским интерфейсом, фильтрами, поиском и быстрым редактированием.
* **Swagger UI:** интерактивная документация для фронтендеров по адресу `/swagger/`.

## 📡 Список эндпоинтов API

### 🔐 1. Аутентификация (`/api/auth/`)
* `POST /api/auth/register/` — регистрация нового мастера/пользователя.
* `POST /api/auth/token/` — вход по логину и паролю, получение JWT-токенов (`access` и `refresh`).
* `POST /api/auth/token/refresh/` — обновление `access` токена.
* `GET /api/auth/me/` — информация о текущем авторизованном пользователе.

### 🛠 2. Каталог услуг (`/api/services/`)
* `GET /api/services/` — каталог услуг с пагинацией (по 5 штук), фильтрами, поиском и сортировкой.
* `POST /api/services/` — добавление новой услуги (только авторизованный мастер).
* `GET /api/services/{id}/` — детальная информация об услуге.
* `PUT/PATCH /api/services/{id}/` — редактирование услуги (только автор или админ).
* `DELETE /api/services/{id}/` — удаление услуги (только автор или админ).
* `GET /api/services/top/` — **Топ-5 популярных услуг** для главного экрана (отдается мгновенно из кэша).
* `GET /api/services/my-services/` — список услуг текущего мастера.

### 📋 3. Заявки клиентов (`/api/orders/`)
* `POST /api/orders/` — создание заявки («Заказать»). Доступно любому клиенту/гостю без регистрации!
* `GET /api/orders/` — список заявок. Мастер видит **только свои** заявки. Админ видит **все**.
* `GET /api/orders/{id}/` — просмотр конкретной заявки.
* `DELETE /api/orders/{id}/` — удаление заявки (разрешено **только Администратору**).

## 💡 Примеры HTTP-запросов

### 1. Получение токена мастера (Вход)
`POST http://127.0.0.1:8000/api/auth/token/`
```json
{
  "username": "master_santehnik",
  "password": "master123"
}
```
**Ответ сервера (200 OK):**
```json
{
  "refresh": "eyJhbGciOiJIUzI1NiIsIn...",
  "access": "eyJhbGciOiJIUzI1NiIsIn..."
}
```

`GET http://127.0.0.1:8000/api/services/?category=repair&search=стиральной&ordering=-price`

`POST http://127.0.0.1:8000/api/services/`
